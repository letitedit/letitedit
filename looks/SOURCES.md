# Looks: where the numbers come from

The recipes of the library Looks below carry tags like `[JH]` or `[ASC]` after a number or a rule, so the AI (and a
person) can see how much weight each carries: Word-pop talking head, Lots going on, Storytime, Podcast clip split
screen, Beat-synced montage, Faceless list, Clean explainer, Documentary, Cinematic travel, Aesthetic
day-in-the-life, Product ad (UGC), Meme commentary, High-energy challenge, Travel vlog, Podcast episode and Product
review. They are written in letitedit's own words: no text, preset file, picture, sound, font or music was copied
from any source below; numbers are used as facts. Every file a Look ships is letitedit's own or from the asset
library (CC0, MIT) and is listed in its settings' `credits`. Every tagged claim was checked on the source page itself
(29 and 30 Oct 2026); claims that could not be checked are tagged `[UNV]`. No creator is named in any Look.

## Sizes

Sizes in a Look's settings are pixels at 1080 high, scaled with the project's height. On a vertical 1080x1920
project everything draws 1.78x bigger: a caption `size: 80` is about 142 px tall type, 7.4% of the frame height. So
`[ASC]`'s 80-120 px is about `size` 45-67 and `[BLZ]`'s 6-8% of the height is about `size` 65-87.

## What would make the numbers stronger

- The person's own reference videos, measured with Learn from a video (`letitedit_learn`, `letitedit_measure`).
- None of the sources above publishes a randomised test; the retention claims are vendor-reported. A channel's own
  analytics beat every number here `[JH]`.
