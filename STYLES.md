# Style packs are retired

Everything is a Look. The current interface and format are in
[LOOK-SETTINGS.md](LOOK-SETTINGS.md). My style is now My Looks; Import a style is
part of Learn from a video. There is no public style-pack catalogue or writer.

The former interface is archived in `dev-history/styles-before-t292.md`, not a
current editing reference. Old finished timelines remain valid; their metadata
is read through the legacy Look reader without applying a new edit.
