# letitedit-broll: what `follow_motion` changes

Read it when a Look's recipe asks for `follow_motion`. Every rule is in SKILL.md; this file holds the tool's detail
behind one of them.

## 7. Check

`follow_motion: true` is an option for a Look whose reference pans with the scene's own motion (its recipe says so),
not a default to switch on: it only changes shots that already move a little (their own direction is topped up) and
leaves static shots the whole vocabulary. The camera pans right when the picture slides left.
